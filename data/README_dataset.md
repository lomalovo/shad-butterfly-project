**Шаблон названия фотографии:**
<идентификатор-iNaturalist>.jpg

**Формат таблицы preliminary_annotations.csv:**
- photo_id - уникальный идентификатор фотографии iNaturalist
- observation_id - идентификатор наблюдения iNaturalist (типа альбом)
- file - путь к фотографии (images/photo_id.jpg)
- original_url - ссылка на фото в iNaturalist
- license_code - везде cc0
- attribution - везде no rights reserved
- observer_login - логин того, кто опубликовал
- taxon_id - идентификатор наблюдения (тема альбома)
- taxon_name - название по идентификатору выше
- width - ширина фото в пикселях
- height - высота фото в пикселях
- sha256 - контрольная сумма файла
- provisional_group - группы из начала файла (single, multiple, lookalike, background)
- count - количество взрослых бабочек (zero, one, multiple)
- negative_kind - тип, если нет взрослых бабочек (пустое поле: там где есть взрослые бабочки, immature: гусеница/куколка, other_insect, other_similar, ordinary: фон)
- small_object - маленькая бабочка относительно кадра (yes, no, unknown, na)
- occluded - часть бабочки закрыта другим объектом (yes, no, unknown, na)
- edge_cut - часть бабочки обрезана границей фото (yes, no, unknown, na)
- complex_background - сложный, пестрый или маскирующий фон (yes, no, unknown)
- close_objects - бабочки близко друг к другу (yes, no, na)
- blur - заметное размытие (yes, no, unknown)
- poor_light - сложное освещение, низкий контраст, тени (yes, no, unknown)
- lookalike_present - другие объекты, похожие чем-то на бабочку, моли не в счет (yes, no)
- suspected_duplicate - похоже на другой снимок (yes, no, unknown)
- wings - положение крыльев (open, closed, mixed, unknown, na)
- view - ракурс относительно тела бабочки, не горизонта! (top: сверху/снизу, side, oblique: под углом, mixed, na)
- background - преобладающий фон вокруг бабочки (foliage: листва/трава/зеленое, flower, bark_ground: земля/кора/камни/коричневое, plain: какой-то однородный фон, other: другое/вода/синий)

**Отличие unknown и na:** unknown = не точно/может быть/может не быть, na = неприменимо (например, у гусеницы характеристика крыльев)

**Основные поля в таблице:** photo_id и original_url, остальное полезно для подготовки инструкции, экзамена, пилота, запуска разметки, воспроизводимости, проверки происхождения, анализа и тд.
